# 💫 맛슐랭 지도

메모장에 적던 맛집 미슐랭을 지도에서 보고 편집하는 웹앱. 폰 홈 화면에 추가해 앱처럼 쓴다.

- 카카오맵 위에 등급별 색 핀 (💫💫💫 진홍 · 💫💫 빨강 · 💫 주황 · 🌝 금색 · 🔖 가볼곳 파랑), 핀 안 이모지는 음식 종류
- 등급 / 종류 / 지역 / 폐업 필터, 목록(등급순·최근 방문·가까운 순)
- 지도 탭 또는 가게 이름 검색으로 추가, 편집, 삭제, "올해도 갔어요"
- 메모장 형식 그대로 붙여넣어 일괄 가져오기 → 카카오 장소 검색으로 위치 자동 찾기
- 구글 시트에 저장 (폰·맥·배우자 기기 동기화, 시트에서 직접 수정 가능). 시트 없이 기기에만 저장하는 로컬 모드도 됨

## 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 앱 |
| `parser.js` | 메모장 형식 파서 (`node -e "require('./parser.js')"`로 테스트 가능) |
| `config.js` | 카카오 JavaScript 키 |
| `apps-script/Code.gs` | 구글 시트 저장소 (Apps Script 웹앱) |
| `맛슐랭_메모_원본.txt` | 가져오기용 원본 메모 |

## 1. 카카오 지도 키 (5분)

1. https://developers.kakao.com 로그인 → **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름: 맛슐랭)
2. **앱 키**에서 **JavaScript 키** 복사
3. **앱 설정 → 플랫폼 → Web 플랫폼 등록**, 사이트 도메인에 아래를 한 줄씩 추가
   - `http://localhost:8000`
   - (폰용으로 배포한 뒤) `https://<깃허브아이디>.github.io`
4. **제품 설정 → 카카오맵 → 사용 설정 ON** (신규 앱은 이걸 켜야 지도가 뜬다)

## 2. 맥에서 실행

```sh
cd ~/학습/맛슐랭
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 → 설정 창에 JavaScript 키 입력 → 저장.
설정 → **메모장 내용 가져오기**에 `맛슐랭_메모_원본.txt` 내용을 붙여넣고 → 미리보기 → 가져오기 → 위치 자동 찾기.

자동으로 찾은 위치는 점선 핀으로 표시된다. 핀을 눌러 **맞아요**를 누르거나 **다시 찾기**로 고친다.
해외 맛집은 카카오 검색이 안 돼서 도시 중심에 대략 표시되니, 상세에서 **지도에서 지정**으로 옮기면 된다.

## 3. 구글 시트 연동

1. 새 구글 시트 만들기 (이름: 맛슐랭)
2. **확장 프로그램 → Apps Script** → `apps-script/Code.gs` 내용을 붙여넣고 저장
3. 함수 목록에서 `setup` 선택 → **실행** → 권한 허용 → 실행 로그에 나온 **토큰** 복사
4. **배포 → 새 배포 → 유형 선택: 웹 앱** / 실행 사용자: **나** / 액세스 권한: **모든 사용자** → 배포 → **웹 앱 URL** 복사
5. 앱 설정에 URL과 토큰 입력 → 저장. 이미 기기에 데이터가 있으면 시트에 올릴지 물어본다.

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영된다.
URL을 아는 사람도 토큰이 없으면 읽기·쓰기가 안 된다.

## 4. 폰에서 쓰기 (GitHub Pages)

폰의 위치 기능과 홈 화면 앱은 https 주소가 필요하다.

1. GitHub에 새 저장소(예: `matchelin`)를 만들고 이 폴더의 파일을 올린다 (`맛슐랭_메모_원본.txt`는 빼도 된다)
2. 저장소 **Settings → Pages → Branch: main / (root)** → 저장
3. 몇 분 뒤 `https://<아이디>.github.io/matchelin/` 접속 가능 → 카카오 Web 플랫폼에 `https://<아이디>.github.io` 추가
4. 맥 앱의 설정 → **다른 기기용 설정 링크 복사** → 그 링크를 폰에서 열면 키·시트 설정이 자동 입력된다
5. 아이폰 Safari: 공유 → **홈 화면에 추가**

시트 URL·토큰은 저장소에 넣지 않고 설정 링크로만 전달한다 (공개 저장소에 올라가지 않도록).
설정 링크에는 토큰이 들어 있으니 믿을 수 있는 사람에게만 보낸다.
